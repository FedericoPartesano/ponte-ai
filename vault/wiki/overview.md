# Ponte AI

App desktop (Electron) che collega il PC a un'applicazione web: la chat dell'applicazione arriva al PC, dove la lancia la Claude Code locale. Il canale è inverso (il PC si connette al server), con un **codice di abbinamento** per instradare le chat quando più persone condividono lo stesso account.
